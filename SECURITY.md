# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

This application runs entirely offline with no network access. All data is stored locally on your machine.

If you discover a security concern, please open an issue on GitHub — do **not** open a public issue for critical vulnerabilities. Instead, email the maintainer directly via the contact information in the repository profile.

We aim to acknowledge reports within 48 hours.
